# Planetarium

An animated tour of the solar system for Android, built with Flutter and based on
the **XORE** mobile interaction concept (astronaut helmet, planet reflected in the visor).

## What's inside

- **Intro**: the planet name spins in like a slot machine while the astronaut rises into view.
- **Home**: the selected planet rotates live in the helmet visor. Swipe, tap the arrows or tap a
  dot on the arc selector to switch planets; the giant vertical name cascades between them.
- **Dive**: tap the visor (or swipe up) to fly through it into space.
- **Space view**: the planet's horizon under a sun flare, with a satellite, twinkling stars and
  shooting stars. Scroll down to travel to its moon (a lander touches down) or, for Mercury and
  Venus, to the Sun.
- **Detail**: *Read more* flies the planet into the header. Tabs: Discover (gallery and story),
  Facts (animated counters and a to-scale size comparison), History (exploration timeline) and
  Diagram (live orbit map and an interior cutaway).
- **Explore**: search all 15 bodies from the grid or search icon.

Every planet, moon and the Sun is drawn in real time by one GPU fragment shader
(`assets/shaders/planet.frag`), with clouds, city lights, craters, storm bands and rings. No image
assets ship with the app, which keeps the APK small (about 8.6 MB for arm64).

## Build

```sh
flutter pub get
flutter build apk --release --split-per-abi   # per-ABI APKs
flutter build apk --release                   # one universal APK
```

The launcher icons and splash are generated by `python3 tool/make_icons.py` (numpy + Pillow).

Release builds are currently signed with the debug key. Add your own keystore in
`android/app/build.gradle.kts` before publishing to Google Play.
